# 运行耐久压力测试

仓库自带四路和九路合成压力测试，覆盖稳定、突发和极端输入。测试不访问网络，也不使用真实
直播或用户数据。

## 加速检查

```bash
SOAK_DURATION_MS=300000 pnpm test:soak
```

这里的时长是模拟时长。加速模式会快速推进单调时钟，适合开发和 CI。输出包含两种实例规模的
接收数、丢弃数和峰值 heap。

## 真实时间检查

先运行无 DOM 的真实时间调度检查：

```bash
SOAK_DURATION_MS=21600000 SOAK_REALTIME=true pnpm test:soak
```

稳定版还应运行 Chromium 真实 DOM 检查：

```bash
pnpm test:soak:browser
```

该命令运行 6 小时，把总时间分配给四路和九路两种实例规模。输出记录实际 DOM 峰值、FPS、
最大帧间隔、Long Task 次数与时长，以及 Chromium 可用时的 JS heap 起始、峰值和结束值。

不要把长时任务放进托管 CI。仓库 CI 不运行耐久检查，加速检查、真实时间检查和浏览器报告都
在本机或专用发布候选环境运行并保存。

## 验收

测试持续断言：

- 每个弹幕与事件等待队列不超过默认上限；
- 可见集合不超过配置；
- 九路共享卡片、完整卡和高成本动画不超过全局预算；
- 极端输入时 dropped 持续增加；
- 销毁后计时任务、实例注册和活跃 grant 归零；
- heap 增量不随历史消息数无界增长。

常规 `pnpm test:browser` 另行验证短时三浏览器生命周期和四路/九路 DOM 上限。耐久结果应
与当次版本、浏览器和构建产物一起保存。
